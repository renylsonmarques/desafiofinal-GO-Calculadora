# Calculadora em Go

Este projeto faz parte do último desafio do curso de Go da DIO.me.

Aqui eu apliquei os conhecimentos que adquiri ao longo do curso para construir uma calculadora simples em Go, com as operações básicas de soma, subtração, multiplicação e divisão.

## Objetivo

O objetivo deste projeto foi praticar os fundamentos da linguagem Go, como:

- criação de funções
- uso de pacotes
- testes automatizados
- organização básica de um projeto

## Funcionalidades

- somar dois números
- subtrair dois números
- multiplicar dois números
- dividir dois números

## Estrutura

- calculadora.go: código principal da calculadora
- calculadora_test.go: testes das operações matemáticas
